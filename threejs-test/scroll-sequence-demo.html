滚动驱动的序列帧动画系统

这个 demo 用的是图像序列帧思路，不是纯 CSS 切图，也不是视频自动播放。中间主场景由 `canvas` 接管渲染，滚动条只负责提供进度，文案、标注、景深光层则继续交给 DOM 做位移和透明度联动。

Driver scroll → progress → frame → render

现在这个 demo 已经改成真实远程 WebP 序列帧加载。默认按你给的 heygears 地址规则去取 `00000.webp ~ 00156.webp`，再按滚动进度映射到对应帧。

How It Works

结构是拆开的，体验才稳

这个页面故意把责任分成三层：滚动只产出进度，序列帧只负责画面，DOM 只处理信息层。后续你要接真实资产、加多段场景或者接 GSAP / Lenis，都有清晰落点。 

const progress = clamp((scrollY - start) / distance, 0, 1);
const frameIndex = Math.round(progress * (frames.length - 1));
drawFrame(frames[frameIndex]);
